# 📜 Code of Conduct

## Our Pledge

We are committed to making participation in this project and community a welcoming, respectful, and positive experience for everyone.

We welcome contributions from people of all backgrounds, experience levels, and skill sets.

As contributors and participants, we are committed to creating an environment where everyone can learn, collaborate, and contribute respectfully.

---

## 🤝 Expected Behavior

Participants and contributors are expected to:

- Be respectful and considerate towards others.
- Communicate professionally and constructively.
- Welcome beginners and help others learn.
- Provide constructive feedback on issues and pull requests.
- Respect different opinions, approaches, and perspectives.
- Focus on the project and the community rather than individuals.
- Give appropriate credit to others for their contributions.
- Follow GitHub's community guidelines and project contribution guidelines.

---

## 🚫 Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Offensive, insulting, or disrespectful comments.
- Trolling or deliberately disrupting discussions.
- Sharing inappropriate or offensive content.
- Publishing someone's private information without permission.
- Spam, malicious contributions, or intentionally harmful activity.
- Plagiarism or claiming someone else's work as your own.
- Any other behavior that makes the community unsafe or unwelcoming.

---

## 💻 Contributions

We encourage contributors to participate through:

- Issues
- Pull Requests
- Code improvements
- Bug reports
- Feature suggestions
- Documentation improvements
- Open-source discussions

All contributions should be made with respect for the project, its contributors, and the community.

Before submitting a Pull Request, contributors are encouraged to:

1. Understand the existing project structure.
2. Make focused and meaningful changes.
3. Test their changes where applicable.
4. Write clear commit messages.
5. Provide a clear description of the Pull Request.
6. Respond respectfully to review feedback.

---

## 🔀 Pull Request & Issue Discussions

Healthy discussion and constructive disagreement are encouraged.

When reviewing code or discussing an issue:

- Comment on the code or idea, not the person.
- Explain the reason behind suggestions when possible.
- Be open to alternative solutions.
- Avoid aggressive or disrespectful language.
- Keep discussions relevant to the project.

---

## 🛡️ Reporting Unacceptable Behavior

If you experience or witness unacceptable behavior, please report it to the project maintainers or organizers.

For the **START2CODE** initiative, concerns may also be reported to the:

**GitHub Club**  
**Technova Society**  
**SSCSE, Sharda University**

Reports will be handled respectfully and, where appropriate, kept confidential.

---

## 🌱 Our Goal

The goal of this project is not only to build software but also to create an environment where students and developers can:

**Learn • Build • Collaborate • Contribute**

We believe that respectful collaboration helps everyone improve their technical skills and contributes to a stronger open-source community.

---

## 📌 Enforcement

Project maintainers and organizers are responsible for clarifying and enforcing these standards.

They may take appropriate action in response to behavior that violates this Code of Conduct, including:

- Removing inappropriate comments or contributions.
- Requesting changes to discussions or Pull Requests.
- Temporarily restricting participation.
- Removing access to the project or community when necessary.

---

## 🏛️ Ownership & Community

This project is associated with the **GitHub Club under Technova Society, SSCSE, Sharda University**.

The community is intended to provide a collaborative learning environment for students and contributors interested in Git, GitHub, open source, and real-world software development.
